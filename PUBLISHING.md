# Park Life

A quiet, autonomous cartoon shark world. This repository hosts the publicly accessible playable prototype.

## Publish the approved prototype

1. Upload `Park-Life-GitHub-Pages.zip` to the repository root, keeping that exact name. The ZIP contains `index.html`, `app.js`, `world.js`, `scene.js`, `style.css`, and the `assets/` directory.
2. In **Settings → Pages → Build and deployment**, choose **GitHub Actions**.
3. The **Publish Park Life** workflow deploys the original files without regenerating or editing the approved illustrations.
4. The intended URL is https://saampe.github.io/park-life/.

The original prototype uses simulated signals; Gmail and calendar are not connected. Successful rule tests alone do not verify Safari rendering.

Do not upload the raw `Park-Life-source.zip` for deployment; use the smaller prepared `Park-Life-GitHub-Pages.zip` package.
