# Park Life — approved design
A private web window into an original tall, lanky anthropomorphic shark's independent life in a suburban park. The exact approved visual baseline is `/workspace/approved-art/park-life-approved.png`; preserve its original character design and scenery. Layered 2D was chosen over cel-shaded 3D for fidelity to the hand-drawn cartoon aesthetic. The house and park use original illustrations informed by Regular Show.

The app contains exterior/interior scenes, autonomous low-stakes activities and small discoveries. It follows Stockholm local time (Europe/Stockholm), four seasons and direct land weather. Spring foliage; lush summer; autumn leaves; winter snow/frost and bare trees. Time-of-day influences lighting and activities. Four hours marked busy increases occupied activity likelihood. Each five new emails gives one game-selected parcel via an airborne swimming mail fish; remainder carries forward, no duplicate deliveries. Calendar carries only busy durations and email only counts, never names, titles or contents. No real sources connect in this version; try every rule through clear simulation controls, with live local time available.

While closed, the browser app does not run. On return it reconstructs plausible activity from elapsed time and a persisted random seed, including the possibility of no changes. No loneliness, hunger, neglect or absence penalties. Saves live on this device, best effort if storage unavailable. Simulator is isolated from the real saved world. Simulated email counts and elapsed absence are explicit incremental actions, not repeated on render. No sounds by default, respect reduced motion, keyboard-operable controls, responsive full-scene composition.

First release: browser-local prototype, source/download included, local preview if available. Integrations offered only after user trials. Private hosting is a later sharing step, not a public deployment. Approved artwork is final; only generated cleanplates, transparent extracted actor sprites and a matching new interior are needed for animation.
